# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. In short:

- **Be respectful and inclusive.** Welcome different backgrounds, skill levels, and opinions. Critique code and ideas, never people.
- **Be constructive.** Reviews are specific, actionable, and kind; prefix non-blocking remarks with `nit:`.
- **Be honest.** Never fabricate data, test results, interview answers, or evidence. Disclose AI assistance as described in [CONTRIBUTING.md](CONTRIBUTING.md).
- **Respect privacy.** Do not post personal data of team members or citizens (student IDs, real e-mails, faces, licence plates) in issues, commits, or tests.

Unacceptable behaviour includes harassment, insulting or derogatory comments, publishing others' private information, and other conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Report concerns privately to the repository owner (@nichodarren) or any maintainer. Reports will be handled confidentially. Maintainers may remove, edit, or reject contributions that do not follow this code and may restrict participation for repeated violations, following the enforcement guidelines of the Contributor Covenant 2.1.
